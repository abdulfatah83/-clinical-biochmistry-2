Viral Replication Cycle

Viruses rely on host cellular machinery to copy their genomes, synthesize proteins, and assemble new particles. This quick reference highlights the canonical steps of the lytic cycle along with key molecular events.

Phase 1

Attachment (Adsorption)

Viral surface proteins bind to specific receptors on the host cell membrane. Tropism and host range are determined at this step.

Phase 2

Entry & Uncoating

Virus penetrates via fusion, receptor-mediated endocytosis, or injection. Capsid disassembles, releasing the genome into the cytoplasm or nucleus.

Phase 3

Genome Replication

Nucleic acid is copied using viral polymerases (RNA viruses) or host DNA polymerases (most DNA viruses). Replication occurs in compartments tailored to genome type.

Phase 4

Protein Synthesis

Host ribosomes translate viral mRNA. Early proteins favor replication; late proteins include structural capsid units and envelope glycoproteins.

Phase 5

Assembly & Maturation

New genomes are packaged into capsids. Enveloped viruses acquire membranes from ER, Golgi, or plasma membrane while inserting glycoproteins.

Phase 6

Release

Non-enveloped viruses exit via cell lysis; enveloped viruses bud, preserving host viability for persistent infection.

Key Molecular Highlights

  • Attachment: Interaction between viral attachment protein (VAP) and host receptor (e.g., HIV gp120-CD4).
  • Entry: Membrane fusion mediated by conformational change or endosomal acidification.
  • Replication: RNA-dependent RNA polymerase or reverse transcriptase (retroviruses) produces genomes & mRNA.
  • Protein synthesis: Polyprotein processing, protease cleavage, and post-translational modifications occur.
  • Assembly: Genome packaging signals ensure accurate encapsidation.
  • Release: Host ESCRT complexes can facilitate budding; neuraminidase cleaves sialic acid for influenza release.

Replication Strategies

Genome Type Site Notable Feature
dsDNA (Herpesviridae) Nucleus Uses host polymerase; latency via episomes.
ssDNA (Parvoviridae) Nucleus Requires dividing cells for S-phase enzymes.
+ssRNA (Flaviviridae) Cytoplasm Genome serves directly as mRNA.
-ssRNA (Orthomyxoviridae) Nucleus/Cytoplasm Needs packaged RNA-dependent RNA polymerase.
Retrovirus Cytoplasm → Nucleus Reverse transcription and integration.
dsRNA (Reoviridae) Cytoplasmic factories Keep genome within core particles during transcription.

Host Responses

Pattern recognition receptors (TLR3, RIG-I) detect viral nucleic acids, triggering interferon production and antiviral states. Viruses counteract via antagonistic proteins.

Clinical Correlations

Antivirals target entry (fusion inhibitors), replication (nucleoside analogs), protease activity, or release (neuraminidase inhibitors). Understanding the cycle informs therapeutic intervention.

Study Tip

Pair each phase with exemplar viruses and drugs that act there. Building mnemonics around the order Attachment → Release aids recall for exams.
